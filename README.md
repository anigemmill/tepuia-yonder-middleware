# Te Puia ↔ Yonder Availability Middleware

Middleware API exposing Te Puia experience availability/inventory (from
`ecommerce.tepuia.com`, a nopCommerce storefront powered by Intouch
Technology Group) as clean JSON for the Yonder guest engagement platform.

Status: bootstrapping. See project notes for current findings on the
nopCommerce Web API plugin vs. client-side scraping tradeoff.
